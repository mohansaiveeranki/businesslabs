# Shared project notes

The three task folders are separate workflows with one shared Knowledge Brain API. Run the full local demo from the repository root with the scripts in `scripts/`. See the root `README.md` for Git Bash start and stop commands.

The task implementations are local demonstrations. They use synthetic starter data, rule-based extraction, and lexical search. Review `DESIGN.md` and `EVALS.md` before describing the prototype as model-powered or production-ready.
